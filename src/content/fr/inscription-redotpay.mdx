« RedotPay inscription » demande le chemin du compte, pas une promesse que la carte partira partout. Ce guide reprend les pages d’aide sur le code et la récompense de 5 USD, et les listes de pays relues le **15 novembre 2026**. Il s’adresse aux lecteurs francophones. Il ne vise pas les résidents des États-Unis, exclus par RedotPay, et il ne propose pas l’émission d’une carte aux résidents du Maroc.

## Avant l’app : quatre listes

RedotPay ne publie pas une liste positive des pays acceptés. Elle publie des blocages. Le détail est dans le [guide des pays](/fr/articles/pays-redotpay). En court, à la lecture du 15 novembre 2026 :

- **Nationalité.** [Pays et régions non pris en charge](https://helpcenter.redotpay.com/en/articles/10339263-unsupported-countries-regions), marquée mise à jour cette semaine, nomme 35 lieux. Un citoyen d’un lieu listé ne termine pas le KYC et n’utilise pas le service. L’Ukraine n’y figure plus. La région de Crimée en Ukraine (y compris Sébastopol) y figure. Les États-Unis y figurent. Le Maroc n’y figure pas.
- **Localisation.** [Restrictions d’accès selon la localisation](https://helpcenter.redotpay.com/en/articles/14252906-location-based-access-restrictions) (28 août 2026) : si vous vous trouvez dans un lieu listé, l’app ne s’ouvre pas. L’Ukraine y est encore. Le Maroc n’y est pas.
- **Émission.** [Restrictions d’émission](https://helpcenter.redotpay.com/en/articles/14254838-card-issuance-restrictions), marquée mise à jour cette semaine : un résident ne reçoit ni carte virtuelle ni carte physique, et le lieu ne peut pas être une adresse de facturation. **Le Maroc y figure.** L’Inde, l’Indonésie, le Népal, Singapour, la Turquie, l’Ukraine, la Croatie et la Slovénie aussi. L’Albanie, le Kosovo, le Monténégro et la Macédoine du Nord n’y figurent plus.
- **Livraison.** [Restrictions de livraison](https://helpcenter.redotpay.com/en/articles/14255319-card-delivery-restrictions), marquée mise à jour hier : le plastique ne part pas vers les lieux listés. Le Maroc, la Tunisie, l’Égypte et l’Ukraine y sont. L’Algérie n’était sur aucune des quatre listes. Une absence n’est pas un accord, et le droit local peut interdire ce que l’entreprise ne bloque pas. Cette page ne donne pas de parcours d’inscription pour un pays absent des listes au sens d’une autorisation.

Si vous résidez au Maroc, arrêtez-vous ici pour la carte. Le reste de la page explique le compte et le code pour les lecteurs dont l’émission n’est pas bloquée. Il ne dit pas de commander une carte vers une adresse marocaine.

## Télécharger la bonne app

Le bouton d’inscription de ce site ouvre l’invitation RedotPay. De là, téléchargez l’app depuis l’**App Store** ou **Google Play**, au nom de l’éditeur officiel. Un fichier APK reçu par message n’est pas ce parcours.

## Créer le compte

1. Choisissez créer un compte.
2. Entrez un e-mail ou un numéro de téléphone que vous lisez vraiment.
3. Saisissez le code de vérification.
4. Choisissez un mot de passe que vous n’utilisez pas ailleurs.
5. Terminez la création seulement après le champ du code, ci-dessous.

<h2 id="parrainage">Le code yj8cq, pendant l’inscription seulement</h2>

[How do I use a referral code?](https://helpcenter.redotpay.com/en/articles/10521800-how-do-i-use-a-referral-code) (26 juillet 2026) est court : sur l’écran de connexion ou d’inscription, touchez **Referral Code (Optional)** et entrez le code. Un code de parrainage ne s’ajoute **que pendant l’inscription**. Il ne s’applique plus une fois le compte créé.

Le lien d’invitation en français utilisé par ce site contient déjà `referralId=yj8cq`. Si le champ est encore vide, remplissez-le avant de finir. Le support ne le rattache pas après coup : l’article dit que cela ne fonctionne pas.

## Les 5 USD, à part du code

[How do I use my 5 USDⓈ sign-up reward?](https://helpcenter.redotpay.com/en/articles/10339297-how-do-i-use-my-5-usds-sign-up-reward) (26 juillet 2026) décrit un crédit de **5 USD** pour les nouveaux utilisateurs :

- Il est valable **30 jours** à partir du jour où vous le recevez.
- Il **ne paie pas** les frais de demande de carte virtuelle ou physique.
- Une fois la carte active, il paie un achat en ligne ou en magasin.
- Pour le voir : ouvrez l’app, touchez le solde de 5 USD sur l’accueil, puis **USDⓈ** pour le détail et la date d’expiration.

RedotPay ne dit pas que le code débloque cette récompense. Nous montrons le code et la récompense ensemble pour que le champ soit rempli, et la phrase à côté dit qu’ils sont séparés. Les 10 USD et les 100 USD sont dans le [guide des frais](/fr/articles/frais-redotpay), avec leurs sources.

## Sécuriser, puis le KYC

Avant un dépôt :

- Activez la vérification en deux étapes si l’app la propose, par une app d’authentification.
- Activez le verrouillage de l’app.
- Gardez le mot de passe dans un gestionnaire, pas dans une capture d’écran.

La carte exige une vérification d’identité. Les pages lues pour ce guide ne publient pas un délai en heures ni une liste unique de documents pour chaque pays. L’app affiche le type de pièce pour votre cas. En pratique le flux demande le pays d’émission, le type de document, les photos, puis un selfie ou une courte vidéo, puis l’envoi. Une photo floue, un reflet, ou un nom qui ne correspond pas sont des raisons habituelles de rejet. Attendez la notification. Ne payez personne à l’extérieur pour « faire passer » le dossier.

Si vous vivez dans un pays et que votre document est d’un autre, la page de nationalité parle du citoyen, la page d’émission du résident, et la page de livraison de l’adresse. Ces articles n’expliquent pas chaque combinaison. Regardez l’app avant de payer 10 USD.

## Émettre la carte, seulement si l’app l’affiche

Après un KYC accepté :

- La carte **virtuelle** est **10 USD**, une fois, pris sur le solde. Elle suffit pour payer en ligne.
- La carte **physique** est **100 USD**, une fois. Le bouton de commande affiche le montant. Le paiement confirme la commande.
- Le crédit de 5 USD ne couvre ni l’un ni l’autre.
- Ne payez pas si l’adresse est sur la liste de livraison, et ne payez pas si vous résidez dans un lieu de la liste d’émission. Le Maroc est dans les deux.

Dès que la commande physique est passée, la page d’aide dit que l’on peut payer en ligne comme avec une carte virtuelle sans attendre l’enveloppe. Le retrait au DAB, lui, attend le plastique. Le délai, pour une adresse qui peut recevoir la carte, est dans le [guide de livraison](/fr/articles/livraison-carte-redotpay).

## Déposer après, pas avant d’avoir lu le réseau

Le solde arrive par un dépôt crypto sur le réseau que l’écran Dépôt affiche. Le minimum publié pour l’USDT est 1,00 USDT sur chaque réseau nommé dans l’image du 21 juillet 2026. Un envoi sur un autre réseau n’est pas décrit comme récupérable. Les étapes sont dans le [guide de recharge](/fr/articles/recharger-redotpay). Depuis le 9 novembre 2026, RedotPay a aussi annoncé sur X l’achat d’USDT ou d’USDC par carte bancaire dans l’app, sans chiffre de frais : le montant se lit avant de payer, et une carte RedotPay ne sert pas à cet achat.

## Ce que ce site ne fait pas

Le compte est chez RedotPay. PayCards ne le voit pas, ne le réinitialise pas, et n’ajoute pas un code après coup. Si l’inscription était le seul mot-clé, le chemin publié est : listes, app officielle, code pendant la création, sécurité, KYC, puis la carte seulement quand l’app la propose et que votre lieu n’est pas sur la liste d’émission.
