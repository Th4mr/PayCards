Un code parrainage RedotPay est facultatif, et il est facile de le manquer. La règle du centre d’aide est courte : saisissez-le pendant la création du compte. Après, le champ a disparu. Ce guide est le chemin d’inscription, le code de ce site, et la récompense que les gens confondent avec le code.

Vérifié le **24 octobre 2026**.

Les étapes viennent de [Comment utiliser un code de parrainage ?](https://helpcenter.redotpay.com/en/articles/10521800-how-do-i-use-a-referral-code) (date de page : 26 juillet 2026). Sur l’écran d’inscription, touchez **Referral Code (Optional)** et tapez le code. L’URL d’invitation française utilisée par ce site contient déjà `referralId=yj8cq`. Si l’app affiche encore un champ vide, remplissez-le avant de terminer. Ne créez pas le compte en espérant que le support pourra l’attacher plus tard. L’article dit que ça ne marche pas.

Notre bouton ne met pas l’URL RedotPay dans la page. Il va vers `/go/redotpay-fr`, qui redirige vers cette invitation. C’est un lien de parrainage. L’avertissement est sur la [page d’avertissement](/fr/disclosure). Vous ne payez pas de frais en plus pour l’utiliser.

## Ce que reçoit un nouveau compte

[Comment utiliser ma récompense d’inscription de 5 USD ?](https://helpcenter.redotpay.com/en/articles/10339297-how-do-i-use-my-5-usds-sign-up-reward) (26 juillet 2026) décrit un **crédit de dépenses de 5 USD** pour les nouveaux utilisateurs :

- Il sert à dépenser une fois la carte active.
- Il dure **30 jours** à partir du moment où vous le recevez.
- Il **ne paie pas** les frais d’émission ni de remplacement.
- Vérifiez-le dans l’app sous USDⓈ.

RedotPay ne décrit pas cette récompense comme quelque chose qu’un code de parrainage débloque. Nous montrons le code et la récompense dans la même boîte pour que vous puissiez copier le code, et la phrase à côté dit qu’ils sont séparés. Le [guide des frais](/fr/articles/frais-redotpay) a les lignes d’émission de 10 USD et 100 USD avec leurs sources.

## La vérification, sans délais inventés

Émettre une carte exige une vérification d’identité. Les pages lues ne publient pas un délai unique de traitement, et elles ne publient pas une liste de documents pour chaque pays. L’app montre ce qu’elle acceptera dans votre cas. Si une demande est refusée, corrigez la photo ou le document que l’app nomme. Nous ne citerons pas un taux de réussite que nous n’avons pas mesuré.

Les résidents des États-Unis ne peuvent pas recevoir de carte, les personnes qui s’y trouvent ne peuvent pas ouvrir l’app, et les citoyens américains ne peuvent pas finir le KYC. Les résidents du Maroc ne peuvent pas recevoir de carte. Les listes sont dans le [guide des pays](/fr/articles/pays-redotpay). Payer des frais d’émission avant que l’app montre la carte comme disponible, c’est ainsi qu’on perd les 10 USD ou les 100 USD.

## Une fois le compte créé

1. Utilisez les options de sécurité de l’app avant de déposer.
2. Déposez sur le réseau que l’écran Dépôt affiche. Les réseaux et les minimums ne sont pas un tableau publié unique. Voir [comment recharger](/fr/articles/recharger-redotpay).
3. Émettez la carte virtuelle si les dépenses en ligne suffisent. Commandez la carte physique seulement si vous en avez besoin en magasin ou à un DAB, et seulement si votre adresse n’est pas sur la liste de blocage de livraison.
