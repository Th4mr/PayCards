A RedotPay referral code is optional, and it is easy to miss. The help center’s rule is short: enter it while you create the account. After that, the field is gone. This guide is the signup path, the code on this site, and the reward people mix up with the code.

Checked on **24 October 2026**.

The steps come from [How do I use a referral code?](https://helpcenter.redotpay.com/en/articles/10521800-how-do-i-use-a-referral-code) (page date 26 July 2026). On the registration screen, tap **Referral Code (Optional)** and type the code. The English invite URL this site uses already includes `referralId=yj8cq`. If the app still shows an empty field, fill it before you finish. Do not create the account and hope support can attach it later. The article says that does not work.

Our button does not put the RedotPay URL in the page. It goes to `/go/redotpay-en`, which redirects to that invite. That is a referral link. The disclosure is on the [disclosure page](/en/disclosure). You do not pay an extra fee for using it.

## The 5 USD reward is not the code

[How do I use my 5 USDⓈ sign-up reward?](https://helpcenter.redotpay.com/en/articles/10339297-how-do-i-use-my-5-usds-sign-up-reward) (26 July 2026) describes a **5 USD spending credit** for new users:

- It is for spending after the card is active.
- It lasts **30 days** from the time you receive it.
- It **cannot pay** card issuance or replacement fees.
- Check it in the app under USDⓈ.

RedotPay does not describe this reward as something a referral code unlocks. We show the code and the reward in the same box so you can copy the code, and the sentence next to it says they are separate. The [fees guide](/en/articles/redotpay-fees) has the 10 USD and 100 USD issuance lines with their sources.

## Verification, without invented timelines

Issuing a card requires identity verification. The pages we read do not publish a single processing time, and they do not publish one document list for every country. The app shows what it will accept for your case. If a request is rejected, fix the photo or the document the app names. We will not quote a success rate we have not measured.

Citizenship matters before you start. RedotPay’s unsupported page says citizens of the listed countries cannot complete KYC. The United States is on that list. Delivery of the plastic card is a second, wider list. Both are copied in the [supported-countries guide](/en/articles/redotpay-supported-countries). Paying the issuance fee before the app shows the card as available is how people lose the 10 USD or the 100 USD.

## After the account exists

1. Use the security options in the app before you deposit.
2. Deposit on the network the Deposit screen shows. Networks and minimums are not a single published table. See [how to top up](/en/articles/how-to-top-up-redotpay).
3. Issue the virtual card if online spending is enough. Order plastic only if you need in-store plastic or an ATM, and only if your address is not on the delivery block list.
